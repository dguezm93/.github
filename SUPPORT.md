# Support

Start with the README, examples, troubleshooting notes, and existing issues.

For a reproducible defect, use the bug report form. Include the exact command, expected and actual behavior, environment, and redacted output.

For an improvement, describe the problem before proposing a solution. For questions, use Discussions when available or open a clearly titled issue.

English and Spanish are welcome. These repositories do not provide an uptime or response-time service agreement.
